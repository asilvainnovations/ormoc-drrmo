# Annex 6-B. Pre-audit Checklist for DRRM Transactions

Used in SOP 6-10 step 1, before year-end, by CDRRMO Administration and Training with the City Accountant. Each "No" becomes a corrective action on FIN-F11. The checklist prevents the findings COA most often raises on LDRRMF use; it does not replace COA's own requirements.

**Table 6.42**

*Pre-audit Checklist*

| **No.** | **Check**                                                                                                           | **Evidence**                                                 | **Yes / No / NA** |
|---------|---------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------|-------------------|
| 1       | The LDRRMF was computed on estimated revenue from regular sources, and the computation is filed                     | FIN-F01 signed by the Budget Officer                         |                   |
| 2       | The 70/30 split appears in the appropriation and in the books                                                       | Appropriation ordinance; ledgers                             |                   |
| 3       | Every charge to the 70% is in the approved LDRRMFIP and is a DRRM use                                               | LDRRMFIP line; obligation request                            |                   |
| 4       | Every QRF charge refers to an SP declaration of a State of Calamity in force at the time                            | SP resolution; FIN-F05                                       |                   |
| 5       | Every AA charge refers to a State of Imminent Disaster in force, is within the AA line and passed the tranche check | Mayor's EO; FIN-F06                                          |                   |
| 6       | Unused QRF and 70% balances were transferred to the STF at year-end                                                 | Closing entries                                              |                   |
| 7       | The STF ledger shows each balance by year of origin and its deadline; no balance passed five years unused           | FIN-F04                                                      |                   |
| 8       | Each emergency procurement has its written ground, HoPE approval, documents and posting                             | FIN-F07; BAC records                                         |                   |
| 9       | Each delivery has an inspection and acceptance report                                                               | IAR                                                          |                   |
| 10      | Relief goods and non-food items issued have issue slips and distribution summaries                                  | Issue slips; summaries (no personal data in the CDRRMO file) |                   |
| 11      | No stock on hand is past its expiry date; rotated items have issue records                                          | LOG-F01; count report                                        |                   |
| 12      | Cash advances for DRRM operations were liquidated within the period                                                 | Liquidation reports                                          |                   |
| 13      | Donations have acceptance documents, receipts and use records                                                       | FIN-F09; ORs                                                 |                   |
| 14      | Quarterly utilisation reports were submitted to the CDRRMC and posted under the Full Disclosure Policy              | FIN-F03; posting proof                                       |                   |
| 15      | DRRM property is on the asset register, covered by PAR or ICS, and counted this year                                | Count report                                                 |                   |
| 16      | Insurance of DRRM buildings, warehouses and equipment is current                                                    | GSIS policy schedule                                         |                   |
| 17      | Prior-year COA observations on DRRM funds, stocks and property have a reply and status                              | FIN-F11                                                      |                   |
