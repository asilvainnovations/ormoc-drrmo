# Annex 6-D. Prepositioned Stock Planning Worksheet

Used in SOP 6-11 step 1. One worksheet per priority hazard scenario; the highest result per item sets the level. Figures are entered by the CSWDO and the CDRRMO from the approved contingency plans; none is set in this Manual.

**Table 6.44**

*Stock Planning Worksheet*

| **Line** | **Item**                                                     | **Formula or source**                            | **Entry** |
|----------|--------------------------------------------------------------|--------------------------------------------------|-----------|
| a        | Hazard and scenario                                          | Contingency plan (Chapter 3)                     |           |
| b        | Families to be served, by cluster of barangays               | CP Forms; CDRA exposure                          |           |
| c        | Days of self-reliance before augmentation                    | CP; DSWD Field Office VIII                       |           |
| d        | Packs per family per day (food) / kits per family (non-food) | CSWDO standard                                   |           |
| e        | Target level by item                                         | b × c × d (food); b × d (kits)                   |           |
| f        | National minimum                                             | DPMS Vol. 2: 500 food packs and 500 hygiene kits | 500 / 500 |
| g        | Level adopted                                                | Higher of e and f                                |           |
| h        | Procurement or call-off lead time (days)                     | FIN-F08 agreement                                |           |
| i        | Average daily issue in an event                              | Past events; AARs                                |           |
| j        | Reorder point                                                | h × i, plus a safety margin set by the CSWDO     |           |
| k        | Warehouse split                                              | By cluster and hazard exposure (LOG-F02)         |           |
| l        | Annual cost of holding and rotation                          | Into the stock replenishment line (SOP 6-01)     |           |
