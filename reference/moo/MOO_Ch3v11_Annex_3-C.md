# ANNEX 3-C \| Form 3-02 – Dataset Metadata and Quality Checklist

| **Metadata / quality field**                   | **Check / entry**                                     |
|------------------------------------------------|-------------------------------------------------------|
| Dataset ID, title and description              | Record unique ID, purpose and content                 |
| Source agency and original product reference   | Record issuing authority and original file            |
| Data date, acquisition date and update cycle   | Distinguish source date from download date            |
| Geographic coverage and scale/resolution       | Record City/barangay coverage and suitability         |
| Coordinate reference system and units          | Record original CRS and any transformation            |
| Method, scenario, baseline and time horizon    | Record model/method assumptions and projection period |
| Attributes, legend and classification          | Check classes, units, code lists and interpretation   |
| Completeness, geometry and no-data areas       | Record defects and treatment                          |
| Limitations and uncertainty                    | Record known constraints and prohibited uses          |
| Custodian, access classification and retention | Record responsible office and access controls         |
| Technical validation and approval              | Reviewer, date, comments and approved use             |
