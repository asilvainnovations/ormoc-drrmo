# Annex 7-B. LDRRMP M&E Matrix Template

One row per indicator. Aligned with Form 5D of the Ormoc City DRRM 10-Year Plan and the M&E matrix of the NDRRMP 2020–2030 RBME Plan.

**Table 7.40**

*M&E Matrix Columns (ME-F01)*

| **Column**                   | **Content**                                                               |
|------------------------------|---------------------------------------------------------------------------|
| **Code and result level**    | Unique code; impact, outcome, output or input and process                 |
| **Indicator and definition** | What is counted, how, and what is excluded                                |
| **Unit and disaggregation**  | Unit; sex, age, disability and barangay where relevant                    |
| **Baseline**                 | Value and year, with source                                               |
| **Targets**                  | By year to 2032, as approved by the CDRRMC                                |
| **Data source and method**   | Office records, surveys, SitReps, IAT, database                           |
| **Frequency**                | Quarterly, annual or per event                                            |
| **Responsible office**       | Thematic focal office and data provider                                   |
| **Framework codes**          | Ten Essentials; NDRRMP outcome; DILG pillar; Sendai target; IAT indicator |
| **Current value and status** | Value, date, on-track or off-track, explanation                           |
