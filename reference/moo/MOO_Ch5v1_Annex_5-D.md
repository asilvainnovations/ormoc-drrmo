# Annex 5-D. Recovery Monitoring Matrix Fields (REC-F06)

**Table 5.42**

*Minimum Fields of the Recovery Monitoring Matrix*

| **Field group**    | **Fields**                                                                                           | **Source**               |
|--------------------|------------------------------------------------------------------------------------------------------|--------------------------|
| **Identification** | Event; PPA ID; title; sector; sub-committee; phase (early recovery, short term, medium term)         | REC-F04                  |
| **Location**       | PSGC barangay code(s); site description (no personal data)                                           | REC-F04                  |
| **Link to need**   | PDNA reference; ER-F05 line (if from transition); BBB screen reference                               | PDNA; REC-F02; REC-F07   |
| **Targets**        | Output indicator; target by year; unit; beneficiaries as aggregates by sex, age group and disability | Program                  |
| **Finance**        | Approved cost; fund source; obligations; disbursements                                               | Chapter 6 records        |
| **Implementation** | Implementing office; partner; start and planned completion; percentage physical accomplishment       | Office reports           |
| **Issues**         | Issue; owner; decision; due date                                                                     | Problem-solving meetings |
| **Verification**   | Field validation date; BBB conditions met (yes/no); evidence link                                    | SOP 5-05, 5-07           |
| **Closeout**       | Completion date; closeout evidence; outcome note; lesson reference (Chapter 7)                       | REC-F09                  |

*Note.* Blank means "not reported", never zero. Figures are scoped to one event. The matrix is the event-database extension recommended for A9.3 and links to the A5.4 event database of Chapter 3.
