# ADR-031: Platform coherence — Cebuano UI, pillar-colored Library, Pareto dashboard on Today, Introduction chapter (v1.17.0)

Status: Proposed, 12 Nov 2026, by the lead assessor (Alvin M. Silva). For the CDRRMO Head. No migration: app, seed and reference text only.

## Context

The City asked for a coherent pass across the platform in four directions, in preparation for embedding M&E early and for the 1–4 Dec 2026 validation workshop:

1. **Simple language and Cebuano (Bisaya).** The platform serves duty officers and barangay users whose working language is Bisaya; the copy should read simply and the navigation chrome should speak Cebuano when the user chooses it.
2. **Visual separators in the Library.** Chapters and manual files should group visually into the four DRRM thematic areas (prevention, preparedness, response, recovery) — the 1.14.0 thematic vocabulary already used by protocols — so a reader sees the shape of the manual at a glance.
3. **Pareto dashboard on Today.** A small set of IAT indicators carries most of the readiness gain (the design principle of efficiency); the Today page should show that set live, with met counts and a path to each gap, as the first step toward embedded M&E.
4. **An Introduction chapter.** Every drafted chapter repeats front-matter boilerplate (purpose, method, document control). The City adopted a ten-chapter roadmap (Chapters 1–5 drafted to date); an Introduction states the purpose, the organization and the assessment method once, and carries the manual cover the City supplied.

Two citation corrections ride along, from the fact-validation pass of 11 Nov 2026: the EOC issuance is **NDRRMC Memorandum No. 131, s. 2018** (a Memorandum, not "MC 131" and not a Memorandum Circular), and the White/Blue/Red alert levels trace to the National Disaster Response Plan and RDRRMC VIII Res. No. 12-006, s. 2023 — Memorandum 131 leaves alert codes to each EOC (para. 9.2.2), so the B1.2 basis now names all three. The Gawad KALASAG self-check moves to the **CY 2026 tiers** (Gold ≥ 2.50, Silver 2.00–2.49, Bronze 1.50–1.99) per OCD Memorandum No. 763, s. 2026 applying NDRRMC MC No. 3, s. 2025.

## Decision

1. **Cebuano UI, English canon** (`src/lib/i18n.tsx`). A small string table (English + Cebuano) drives the navigation rail, tab bar, Today hero and greetings, Library section titles, pillar names and the settings language row. The manual text, legal citations, tooltips, protocols and forms stay in English so that citations remain exact and one controlled text exists; this follows the same reasoning as keeping tooltips English (ADR-019). Language persists per device (localStorage), default English; a `mode:lang` window event plus the storage event re-render open tabs. A parity test fails the build if a key is missing or empty in either language.
2. **Pillar colors** (`src/features/library/pillars.ts`, tokens in `src/styles/tokens.css`). The ten functional areas map to the four pillars: prevention = areas 2, 9; preparedness = 1, 3; response = 4, 5, 6, 7, 8; recovery = 10. Four new token pairs (solid + soft) — teal, ochre-amber, rose, violet — are used only for Library block accents, chips and the legend. They deliberately keep clear of the reserved EOC alert colours (white/blue/red), which remain exclusive to the activation level band, board and controls. Tailwind classes are static strings in a map (dynamic class names are purged).
3. **Pareto dashboard on Today** (`src/features/iat/priority.ts`, `ParetoCard` in `TodayPage.tsx`). The priority set is a typed constant — Tier 1: A1.1, A1.2, A2.2, A2.3, A4.1, A4.2; Tier 2: B1.1, B1.2, B1.3, A3.3, A6.1, A6.2, A6.3, B4.1, B4.2, A8.6, A8.8; Tier 3: A4.6, A10.4, A10.6, A10.8, A7.3, A1.8 — 23 indicators in three tiers, chosen for leverage: strategic, CDRRMO-controllable, implementable within about a quarter. The card joins the current IAT cycle's responses to the indicator list and shows met/total per tier with progress bars; the top unmet indicators link to `/assess/:cycle/i/:indicator`. Manual readiness now counts the Introduction (`chapter_no != null`, so 0 counts).
4. **Introduction as Chapter 0** (`reference/moo/MOO_Ch0_Introduction_v1.0.md`, wired in `scripts/generate_seed.py`). Purpose, the ten-chapter roadmap with drafting status, Parts → functional areas → four pillars, document control and citation policy, the assessment method stated once (IAT v1.7: 140 indicators / 22 domains; M vs GP; evidence-gated 0–4; interviews alone cap at 2; maturity index, IMI, Interface Index, compliance rates, gap priority, action plan; the Pareto set), the manual–platform relationship, and a reading guide. The supplied cover is optimized to 274 KB and served at `/moo-cover.webp`; the chapter opens with it. Chapter 4 is retitled "Early Warning, EOC Activation, Incident Management and Emergency Response" per the City's wording; the financing working draft keeps its working number until the full manual is compiled (renumbering is a compilation step, not a content change).
5. **Copy pass.** Today hero, Pareto card and settings copy rewritten in plain language (short sentences, no buzzwords, one idea per card); CTAs say what the user gets.
6. **Citation corrections.** Workbook B-sheet (B1.1, B1.2) and the Chapter 1 drafts (v0.9/v1.0/v1.2) corrected to "NDRRMC Memorandum No. 131, s. 2018"; B1.2's basis names the NDRP and RDRRMC VIII Res. No. 12-006, s. 2023. Regenerated `seed.sql` and parts; existing manual versions on a live database are not rewritten by a re-seed (the Library owns them), new installs get the corrected texts. Gawad KALASAG CY 2026 tiers in `src/features/tools/gk/gk.ts` with updated tests.

## Consequences

- The Cebuano table covers chrome only (~35 keys); extending it is adding a key to both languages — the parity test keeps the two in lock-step. Translating the manual itself is a City decision and would ride the version workflow, not this table.
- The pillar palette is four colors on top of the existing tokens; the EOC alert colors remain untouched, and a test asserts pillar classes never use `lvl-` tokens.
- The priority set is a curated constant, not a computed ranking: it reflects the Pareto judgment of the assessment team and is revised by an assessor, not derived from scores (a data-driven ranking needs more cycles than one baseline).
- The Introduction is a draft like the other chapters: it enters the Library at status draft, only the CDRRMO Head approves it, and the 85-barangay figure and Memorandum 131 readings carry the same provisional caveats as the rest of the manual.
- Chapter numbering: the target roadmap numbers chapters 1–10, with Recovery at 5 and Financing at 6; drafted text keeps working numbers until compilation, so Chapter 5 (financing) will be renumbered 6 without content change. Links and aliases (`MOO Ch.N`) survive renumbering.
