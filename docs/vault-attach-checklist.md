# Vault: attaching the 9 Nov 2026 issuance files (staff checklist)

For CDRRMO and EOC staff with an account that can edit the Document Vault. No keys, scripts or special computer are needed: everything is done in the app. Work through one year at a time and tick each line.

## Before you start

- Unzip the issuance bundle (`Ormoc-DRRM_Issuance-Bundle`) on the office computer. Keep the folder names as they are.
- Sign in to MODE on that computer. Check the internet connection: each file goes up as soon as you save.

## For each line below

1. Open **Vault** and type the number in the search box (for example `EO No. 26, s. 2017`).
2. Open the document. If the page shows **Open file**, a file is already attached: skip the line. A file that is attached is never replaced.
3. Select **Edit**. Under **File**, choose the file named on the line, from the folder shown.
4. Select **Save**. Wait until the page shows **Open file**, then select it once to check the right file opened.
5. Tick the line.

If the save fails, note the line and the message and tell the CDRRMO records focal. Do not attach a file to a different entry.

Not on this list: the annexes inside the bundle (attach by hand only if the records office asks). EO No. 28, s. 2016 is linked to its Drive folder (three page photos); attach the photos only if the records office wants them in the Vault. CDRRMC Res. No. 04, s. 2021: the final version is the one listed below ("Realigning and reappropriating remaining balances of donations", confirmed 12 Nov 2026); skip the other copy.
